# Brag Plan: brag-more

## What is this?
An agent skill that rebuilds a project's GitHub README into a front page worth landing on: animated hero in the project's own colors and fonts, a framed demo, feature cards, honest badges, a quickstart that runs.

## The angle
Before and after, on a real repo. A plain README (coffeeCart's original) gets one command, and the same page comes back as the real thing. The README is the demo, so the video shows only real renders of READMEs this skill made.

## Hook (0 to 2.5s)
A plain default-looking README in a GitHub-style window. "Your README is your front page."

## Key moments
- The `/brag-more` command typed, then the plain README wipes to the polished one (animated hero, badges, nav).
- The polished README scrolls past: hero, framed demo, four feature cards.
- Same skill, different projects and styles: horse-tinder (clean) and horse-tinder (showcase) side by side, with the four style names.
- The laws: nothing invented, every command runs, every link resolves.

## Outro / punchline
"brag-more. Make your README brag."

## User flow worth showing
Entry: a plain README. Key action: `/brag-more`. Result: the polished README.

## Tone
- Preset: default
- Creative direction: quiet confident before and after, dark stage
- Interpretation: soft transitions, one claim per scene, long enough holds to read each line.

## Format: landscape, 1920x1080, 30fps
## Duration: 22.5s (36 beats at 96 BPM)

## Visual identity
- Background: #0b0f14 stage, GitHub-white README surfaces (#ffffff, text #1f2328)
- Accent: #f5a524 amber
- Text: #f0f6fc on the stage
- Display font: Geist 600; mono: Geist Mono 500
- Strongest visual: the same README before and after, real screenshots

## Share copy (draft)
My README looked like a default template. One command and it looks like a launch page. (brag-more, a skill for GitHub READMEs.)

## Audio direction
- Role: warm bed with soft accents. 96 BPM, C major, kick/hat/bass/pad, a pluck lead, taps as soft wood ticks, a chime on the reveal.
- Restraint: SFX quiet, nothing spiky.

## Storyboard (every cut on a beat, 0.625s per beat)
1. Hook, beats 0-4 (0-2.5s): plain README window, words land: "Your README" / "is your front page."
2. Reveal, beats 4-10 (2.5-6.25s): terminal strip types `/brag-more`, README wipes to the polished version. Line: "One command."
3. Show, beats 10-18 (6.25-11.25s): polished README scrolls. Chips arrive one by one: "Animated hero", "Framed demo", "Feature cards".
4. Styles, beats 18-26 (11.25-16.25s): two real READMEs side by side (clean, showcase), chips: clean, bold, minimal, showcase.
5. Laws, beats 26-31 (16.25-19.4s): three ticks arrive one by one: "Nothing invented." "Every command runs." "Every link resolves."
6. Outro, beats 31-36 (19.4-22.5s): wordmark "brag-more", "Make your README brag."

Names and projects shown are real test READMEs (coffeeCart, horse-tinder). The example IP and PIN in them are fictional.
